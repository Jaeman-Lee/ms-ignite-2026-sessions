## 읽는 기준

- 공식 발표, 제품 시연, 고객·공급사 자체 보고와 확인되지 않은 사항을 구분합니다.
- LIVE 방송은 확인한 구간의 요약입니다. 방송 시계와 개별 영상 재생 시각은 서로 다릅니다.
- LAB723은 공식 실습서의 절차 요약이며 직접 실행한 측정 결과가 없습니다.
- 수치의 비교 조건이 부족하면 일반 성능·절감률로 확대하지 않습니다. Preview와 향후 계획도 표시합니다.

Microsoft의 공식 문서 저장소가 아닙니다. 원문·영상·제품명과 상표의 권리는 해당 권리자에게 있습니다. 원본 영상이나 전체 자막은 포함하지 않고 공식 링크와 요약을 제공합니다.
