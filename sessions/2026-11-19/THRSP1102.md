# THRSP1102 · 은행 파일 전송 장애를 에이전트로 조사하기

**에이전트가 전송 장애의 근거를 수집하고, 담당자가 원천 시스템에서 확인한다.**

2026-11-19 · 공식 행사 녹화·YouTube · 업무용 에이전트

## 핵심 내용

- 타운뱅크(TowneBank) | 미국 | 지역 고객과 기업에 은행 서비스를 제공한다. | 맥스밀리언 파블리코프스키가 운영 사례를 공동 발표했다. 파일스닷컴(Files.com) | 미국 | 기업용 파일 전송·관리 서비스를 제공한다. | 웨이드 캘리슨이 공동 발표했다. 07:55 화면은 Copilot과 API 사이에 호출 권한과 감사를 관리하는 게이트웨이를 둔 구성을 보여줬다.
- 15:20 시연에서 자연어 질의로 전송 실패의 원인 후보와 재시도 상태를 조회했다. 17:50에는 읽기 전용 조회도구로 성공·실패·예외를 보고하는 구성을 제시했다.
- 22:40 화면은 사용자 인증, 짧게 만료되는 토큰, 승인 도구만 노출하는 권한, 호출 감사, 사람의 원천 확인을 제시했다.

## 확인 범위

같은 회차의 Microsoft Events 공식 YouTube가 11월 20일 03:17 PST에 공개됐다. 발표와 시연 근거는 행사 다시보기 화면에서 검토했다. 자막 본문과 두 플레이어의 시각 대응, 운영 성과·금융기관별 적용 기준은 미확인이다.
